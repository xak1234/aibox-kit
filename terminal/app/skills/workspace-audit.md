# Workspace audit

Use this skill to understand an unfamiliar project before changing it.

1. Run `pwd` and `ls -lah` in the live terminal.
2. Find the project's README and dependency manifests without traversing unrelated directories.
3. Read the relevant instructions and inspect available tool versions.
4. Run existing non-destructive checks if the user requested a diagnosis.
5. Report observed results, exact paths and unresolved questions.

Do not move, delete or overwrite files as part of an inspection-only task.
Keep discoveries linked to their actual terminal evidence.
